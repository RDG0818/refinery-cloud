NOTE: this repo is a personal rebuild of a project from the Chevron internship.
Key difference: the internship version used Azure SQL Database; this rebuild
uses Table Storage because the Azure for Students subscription used here
blocks new SQL Database logical servers. Swap in real internship specifics
wherever you have them and this doc doesn't.

--- Tech stack ---

8. Why Python for the Functions?
9. Why react-flow for the dashboard instead of D3 or a canvas library?

--- Design decisions ---

11. Walk me through the SQL vs. NoSQL decision for the alert log.
12. What did you give up moving from SQL to Table Storage?
13. If you had SQL Database available, would you switch back?
14. Why BFS for reachability instead of something else (Dijkstra, DFS, a graph library)?
15. Why recompute reachability for the entire graph on every event instead of incrementally updating just the affected branch?
16. Why does recompute_reachability diff against stored state and only patch/log changed twins, instead of always writing status?
17. Every link is stored as two directed relationships (A→B and B→A) — why not one undirected relationship?
18. Why an event-triggered Function (IoT Hub/Event Hub) instead of, say, an HTTP endpoint the simulator calls directly?
19. Why HTTP-triggered functions with anonymous auth for GraphStatus/AlertHistory instead of something with real auth?
20. Why GitHub Pages for the dashboard instead of Azure Static Web Apps, which seems like the more natural fit?

--- The actual Chevron internship project (not the portfolio rebuild) ---
Known facts to build on: real Cisco switch syslogs as the telemetry source,
~200+ servers/switches at the actual scale, Azure-hosted, data arrived
through a DMZ (partly sanitized before it reached you), auth was a reach
goal never implemented, solo build with a manager who advised on Azure,
10-week internship, target users were sysadmins, no real scale problems
at ~200 nodes, used Azure SQL Database (not Table Storage) for the alert
log. Answers with [bracketed placeholders] need your real specifics filled
